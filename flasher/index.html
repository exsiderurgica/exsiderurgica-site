EXS FLASH
Flasher FM1 direttamente dal Nothing via USB-C · Chrome Android · Beta 0.2

1 Firmware sul Nothing

Seleziona il file .fwsc dalla memoria del Nothing. Se hai uno ZIP, estrailo con l’app File del telefono, senza PC. Chrome ne controlla localmente CRC e SHA-256: il firmware non viene caricato su alcun server.

2 Test USB-C del Nothing

Apri questo sito in Chrome su Android, non nel browser interno di ChatGPT. Collega l’FM1 al Nothing con cavo USB-C dati / OTG e accendilo. Concedi a Chrome il permesso MIDI e SysEx. Questo test non scrive il firmware.

3 Aggiornamento

Attenzione: la procedura è sperimentale e non ancora collaudata su FM1 collegato al Nothing. Anche se Chrome vede USB-MIDI, il loader OTA deve riapparire dopo il riavvio. Un flash interrotto potrebbe richiedere strumenti esterni. Per il primo test usa solo TESTA USB-MIDI.

Solo dopo verifica file e dispositivo
Recupero di un aggiornamento Web MIDI interrotto

Usa questa opzione esclusivamente se il dispositivo è rimasto nel loader MIDI OTA, con il medesimo file firmware selezionato in precedenza. Non ripara la modalità WL82 ROM UBOOT: può richiedere un dispositivo di recupero esterno.

EXS FLASH usa WebMIDI su Chrome Android, senza applicazioni o PC, se il loader dell’FM1 risulta compatibile. È un progetto indipendente per M-VAVE FM1. M-VAVE e FM1 sono marchi dei rispettivi proprietari. Il protocollo Web MIDI e il formato pacchetto sono adattati dal progetto Felucca di Leo Kuroshita / Hügelton Instruments (GPL-3.0-only); codice e attribuzioni in LICENSE.txt. Non modifica automaticamente le patch sul dispositivo e non carica firmware sui nostri server. La sola risposta USB FM-1_986 non certifica la versione installata; verifica sempre il display al riavvio.
